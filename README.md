## Reflection

In the imperative version I had to create empty lists and a variable for the biggest book, then change them step by step inside the loop. In the functional version I just described what I wanted with filter(), map(), sorted() and reduce(), and nothing was modified along the way, so the original list stayed the same. The functional code was shorter, but it took me longer to understand at first, especially reduce() and the lambdas. In Task 3 I saw that count_if can be reused for books and for plain numbers just by changing the callback.
